# Design system — Trazo

This file records the incumbent visual world and the rules new screens must follow. It is a living
document; change it in the same pull request as the code that changes the system.

## World

A travel atelier on paper: warm sand, deep forest ink, mint and teal fields, a single orange signal.
Routes are drawn as dotted lines; maps, stamps and price pins are part of the language. The interface
is rounded and generous, but the typography is editorial and confident. It should feel designed by a
person, not generated by a template.

## Tokens

| Token | Value | Use |
|---|---|---|
| `forest` | `#10262A` | Primary ink, dark surfaces, primary button |
| `sand` | `#F2F5F1` | Page ground |
| `mint` | `#CFEAE3` | Soft selected surfaces, activity accents |
| `mint-light` | `#E3F3EE` | Chips, quiet backgrounds |
| `teal` | `#9ADBCB` | Success, highlights, selected chips |
| `orange` | `#FF6B3D` | Single signal: CTA, route pins, focus |
| `orange-dark` | `#E8501F` | Destructive text and error accents |
| `gold` | `#FFD36B` | Draft badges, accommodation accents |
| `border` | `#D5DDD6` | Hairlines and control borders |
| `muted` | `#3F575B` | Secondary text on sand and white |
| `divider` | `#E3EAE4` | Internal separators |

Type: **Bricolage Grotesque** for display (`font-heading`, 700–800, tracking −0.02em), **DM Sans** for
UI and body (400–700). Display max 4.5rem in-app; hero can reach 5.5rem. Body measure 60–70ch.

Radii: pills `999px`, cards `24px`, modals `36px`, inputs `999px`. Shadows are soft and directional
(`0 20px 40px -24px rgba(16,38,42,0.28)`); the existing orange offset hover on primary buttons is a
brand signature and stays limited to primary CTAs.

## Layout

- Authenticated shell: 64px sticky top bar, 1200px max content, 24–32px gutters.
- Landing: editorial two-column hero, then two path choices, then the AI composer, then destination
  cards. The first viewport must say who we are before it asks for a prompt.
- Workspace: split view on desktop (chat 380–420px, context flexible), stacked on mobile.
- Plan: hero, day tabs, timeline, sticky budget bar. The budget bar is fixed to the viewport bottom
  and the content reserves space for it.
- Catalog: destination grid with a featured first card; detail page uses tabs for hotels, activities
  and transport.

## Components

- `Button`: primary (forest), cta (orange), outline, ghost, icon. Pill shape. Never use a second
  orange button in the same action group.
- `Chip`: filter/answer control; active uses teal or forest, never orange.
- `Badge`: status; text is always present. Draft = gold, saved = forest, published = teal,
  archived = border.
- `Modal`: sand surface, 36px radius, close icon, Escape and backdrop close.
- `Input`: 50px min height, pill, 1.5px border, orange focus ring.
- Item cards: 18px radius, white surface, icon tile, name + meta + price; actions are quiet until
  hover/focus, always visible on touch.
- Empty states: one sentence of guidance plus one primary action; no decorative filler.

## Motion

- One authored entrance per surface: a soft fade/translate on the hero and a staggered reveal for
  lists. Duration 240–520ms, exponential ease-out.
- The AI composer expands with height/opacity; generation stages advance with a subtle pulse.
- Route lines can draw once on the landing. Respect `prefers-reduced-motion`.

## Voice

Spanish (Colombia), warm and concrete. Name the place and the action. Prefer “Cambiar hotel” over
“Modificar elemento”. Errors say what happened and how to recover. Never use “¡Potencia tu viaje!” or
generic marketing filler.

## PDF

The PDF is a client-facing brand artifact: forest cover band, vector logo, mint/orange route marks,
warm paper gradient, topographic watermark, budget card, day cards with type icons, and a footer with
page numbers. It is generated server-side from persisted data; no price is recalculated in the client.
